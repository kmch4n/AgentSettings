# Release Checklist

## Code Quality
- [ ] No FIXME / HACK / XXX comments remaining in changed files
- [ ] No commented-out code blocks left in changed files
- [ ] No debug print statements / console.log left in production code

## Documentation
- [ ] README is up to date
- [ ] CHANGELOG.md has an entry for this version
- [ ] API-breaking changes are documented

## Version
- [ ] Version number updated in package.json / pyproject.toml / Cargo.toml
- [ ] Version follows semantic versioning (MAJOR.MINOR.PATCH)

## Tests
- [ ] Test files exist for changed modules
- [ ] No known failing tests

## Git
- [ ] All changes are committed
- [ ] Branch is up to date with main
- [ ] No merge conflicts
