# standup スキル

git log から当日（または指定期間）の作業内容をサマリーし、スタンドアップや日報に使える形式で出力する。

## 引数の処理

`$ARGUMENTS` を解析する:
- 引数なし → 当日分（today）
- 数値（例: `3`）→ 過去 N 日分
- 日付（例: `2026-03-25`）→ 指定日分
- `week` → 今週分

## ステップ1: git log の取得

```bash
# 当日分の場合
git log --since="$(date +%Y-%m-%d) 00:00:00" --until="$(date +%Y-%m-%d) 23:59:59" \
  --pretty=format:"%h %s" --author="$(git config user.name)"

# 変更ファイルの一覧
git diff --name-only HEAD~$(git log --since="$(date +%Y-%m-%d)" --oneline | wc -l) HEAD
```

コミットが0件の場合は、ステージング済みや未ステージの変更も確認する。

## ステップ2: 作業内容の分類

コミットメッセージの gitmoji を参考に作業を分類する:
- ✨ 新機能
- 🐛 バグ修正
- ♻️ リファクタリング
- 📝 ドキュメント
- 🔧 設定・環境
- その他

（分類用の抜粋。コミットメッセージを書くときは `gitmoji` skill のカタログを使う）

## ステップ3: サマリー生成

以下の形式で出力する（ファイルには書き出さない）:

```
## 作業サマリー（<日付>）

### やったこと
- <作業内容1>
- <作業内容2>

### 変更したファイル
- <主要ファイル（多すぎる場合はモジュール単位でまとめる）>

### 明日やること（未完了タスクがあれば）
- <未完了の作業>
```

## 注意事項
- コミットメッセージをそのまま列挙するのではなく、人間が読みやすい文章に変換する
- 技術的な詳細よりも「何を達成したか」にフォーカスする
